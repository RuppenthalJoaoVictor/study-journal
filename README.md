# Diário de Estudos

> Registro público da minha jornada de estudo em desenvolvimento de software.
> Cada entrada corresponde a um dia real de estudo — inclusive os dias ruins.

[![Última atualização](https://img.shields.io/badge/diário-atualizado%20diariamente-blue?style=for-the-badge)](#-o-que-registro)

## 📅 Por que isso existe

Um currículo mostra o **resultado**, mas não mostra o **processo**. Este
repositório existe para deixar o processo visível: o que tentei, onde travei, o
que entendi e o que não entendi.

Com isso eu ganho duas coisas:

1. **Revisão real.** Reler minhas próprias notas é como eu descubro lacunas.
2. **Evidência de constância.** Não é sobre estudar todo dia — é sobre não
   desaparecer por semanas sem registro.

## 📐 Formato das entradas

Cada entrada vive em `diario/AAAA-MM-DD.md` e segue sempre a mesma estrutura:

```markdown
# AAAA-MM-DD — <assunto principal>

## 🎯 Objetivo
O que eu pretendia aprender hoje.

## 🧠 O que aprendi
Conceitos realmente assimilados, com exemplos de código.

## 🧱 O que travou
Onde me perdi, com o motivo. Esta seção é a mais importante do diário.

## ✅ Amanhã
O que eu pretendo fazer na próxima sessão.
```

Registrar **o que travou** é proposital. Um diário onde tudo deu certo não
serve para nada: o valor está em documentar as dúvidas.
